# 그린 맵 (Green Map-Z) — APK 빌드 방법

PC에 아무것도 설치하지 않고, **GitHub Actions**를 이용해서 APK를 자동으로 빌드합니다.

## 1. GitHub에 저장소 만들기
1. https://github.com 에 로그인 (계정 없으면 무료로 가입)
2. 우측 상단 `+` → `New repository` 클릭
3. 이름은 아무거나 (예: `green-map-z`) → `Create repository`

## 2. 이 프로�트 폴더를 업로드
1. 방금 만든 저장소 페이지에서 `uploading an existing file` 링크 클릭
   (또는 저장소 페이지 → `Add file` → `Upload files`)
2. 이 zip 안의 **모든 파일과 폴더**를 통째로 끌어다 놓기
   - `.github` 폴더도 반드시 포함되어야 합니다 (숨김 폴더처럼 보일 수 있음)
3. 하단에 `Commit changes` 클릭

> 참고: 브라우저 업로드는 폴더째로 드래그하면 하위 파일까지 함께 올라갑니다.
> 만약 `.github/workflows/build-apk.yml` 파일이 안 보이면, 파일 탐색기에서 숨김 파일 표시를 켜고 다시 시도하세요.

## 3. 자동 빌드 확인
1. 파일을 올리면 자동으로 빌드가 시작됩니다.
2. 저장소 페이지 상단 `Actions` 탭 클릭
3. `Build Android APK` 워크플로우가 실행 중인 것을 확인 (노란 점 → 초록 체크로 바뀌면 성공, 약 3~5분 소요)

## 4. APK 다운로드
1. `Actions` 탭 → 방금 완료된 워크플로우 클릭
2. 페이지 하단 `Artifacts` 섹션에서 `green-map-z-debug-apk` 클릭 → zip 다운로드
3. 압축을 풀면 `app-debug.apk` 파일이 있습니다.

## 5. 안드로이드 폰에 설치
1. `app-debug.apk`를 폰으로 전송 (카카오톡 나에게 보내기, 이메일, 구글 드라이브 등)
2. 폰에서 파일 탭 → "출처를 알 수 없는 앱" 설치 허용 → 설치
3. 카메라/위치 권한 요청 시 허용

---

## 참고 사항
- 이 워크플로우는 **디버그(debug) APK**를 만듭니다. 테스트/개인 사용에는 문제없지만,
  구글 플레이스토어에 정식 배포하려면 서명(release/keystore) 과정이 추가로 필요합니다.
- AI 식물 인식은 앱이 최초 실행될 때 브라우저 내에서 모델을 다운로드합니다(수십 초 소요, 와이파이 권장).
- 코드를 수정하고 싶다면 GitHub에서 파일을 직접 고치고 커밋하면, 다시 자동으로 APK가 빌드됩니다.
